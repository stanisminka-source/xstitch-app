# Таблица цветов DMC

`src/data/dmc.ts` — 454 цвета DMC Mouliné: номер, название и приблизительный экранный цвет.
Источник: пакет **dmc** Шарлы Гелфанд (https://github.com/sharlagelfand/dmc, лицензия MIT —
текст в `LICENSE-sharlagelfand-dmc.md`), с исправлениями из конструктора схем.
Цвета приблизительные: номер и название точные, оттенок на экране — ориентир.
