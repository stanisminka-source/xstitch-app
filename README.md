# Smile & Stitch

Личное офлайн-приложение для вышивки крестом (PWA): просмотр схемы, выделение символа, учёт вышитого. Работает на Android, iPhone и iPad без интернета после первого открытия.

## Схемы

Схемы загружаются в приложение с устройства и хранятся только на нём. В репозитории — только код и синтетические тестовые схемы. Формат файла описан в `src/pattern/format.ts`.

## Разработка

```bash
npm install
npm run dev      # локальный сервер
npm test         # тесты
npm run build    # сборка в dist/
```

Тесты `tests/*.local.test.ts` проверяют настоящие схемы, если они лежат на диске (пути — в переменных `XSTITCH_PATTERN_JSON` и `XSTITCH_PATTERN_PDF` или в файле `tests/paths.local`, который в репозиторий не входит), и пропускаются, если файлов нет.

Публикация на GitHub Pages идёт автоматически при каждом обновлении ветки `main`.
